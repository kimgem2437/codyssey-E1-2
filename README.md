# 뮤지컬 맞히기 퀴즈

Python으로 만든 터미널 기반 뮤지컬 퀴즈 게임입니다.

등장인물, 줄거리, 대표 넘버 등의 설명을 보고 알맞은 뮤지컬 작품을 맞히는 방식으로 진행됩니다.

## 주제 선정 이유

평소 관심 있는 뮤지컬을 주제로 선택하여 Python의 클래스, 함수, 리스트, 예외 처리와 JSON 파일 저장 방식을 연습하기 위해 제작했습니다.

## 실행 환경

- Python 3.10 이상
- 외부 라이브러리 사용 없음

## 실행 방법

프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
python3 main.py
```

## 주요 기능

1. 뮤지컬 퀴즈 풀기
2. 새로운 퀴즈 추가
3. 등록된 퀴즈 목록 확인
4. 최근 점수와 최고 점수 확인
5. 퀴즈와 최고 점수 저장
6. 저장된 데이터 불러오기
7. 잘못된 입력과 파일 오류 예외 처리
8. `Ctrl+C`와 `EOF` 입력 시 안전 종료

## 프로그램 구성

### Quiz 클래스

퀴즈 한 문제의 정보를 관리합니다.

- 문제
- 선택지 4개
- 정답 번호
- 문제와 선택지 출력
- 정답 확인
- JSON 저장용 딕셔너리 변환

### QuizGame 클래스

퀴즈 게임 전체를 관리합니다.

- 메뉴 실행
- 퀴즈 진행
- 퀴즈 추가
- 퀴즈 목록 출력
- 최근 점수와 최고 점수 관리
- JSON 데이터 저장
- JSON 데이터 불러오기

## 파일 구조

```text
musical-quiz-game/

```

## state.json

`state.json`에는 다음 데이터가 UTF-8 형식으로 저장됩니다.

- 등록된 퀴즈 목록
- 최고 점수

프로그램을 종료할 때 데이터를 저장하고, 다음 실행 시 저장된 데이터를 다시 불러옵니다.

`state.json`이 없거나 JSON 내용이 손상된 경우에는 기본 퀴즈로 안전하게 시작합니다.

## 입력 예외 처리

다음과 같은 잘못된 입력을 처리합니다.

- 아무것도 입력하지 않은 경우
- 숫자 대신 문자를 입력한 경우
- 메뉴 또는 정답 범위를 벗어난 숫자를 입력한 경우
- `Ctrl+C` 또는 `EOF`로 입력을 중단한 경우
